# Data Structures and Algorithms (DSA)

Welcome to my DSA learning repository!

This repository is where I'll be documenting my journey through **Data Structures and Algorithms** as part of my BCA semester syllabus.

I'm starting from the very beginning, so expect to find concepts, definitions, algorithms, examples, and a fair amount of me trying to understand why certain things work the way they do. 

The goal isn't just to prepare for exams. I also want to build a proper understanding of how data is organised, processed, and managed using different data structures and algorithms.

Will everything make sense immediately? Probably not. But that's kind of the point of learning, isn't it?
