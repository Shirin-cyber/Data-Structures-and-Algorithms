# Module 4: Sorting and Searching

Module 4 is all about organising and finding data.

We'll explore different sorting and searching techniques, understand how their algorithms work, and look at hashing as another way of accessing data efficiently.

There are quite a few algorithms here, so I'm expecting some diagrams, examples, and probably a little trial and error along the way.

## 📖 Topics Covered

- Definition of Sorting
- Classification of Sorting:
  - Internal Sorting
  - External Sorting

### 2. Internal Sorting Algorithms

  - Algorithm

### 3. External Sorting Algorithms

### 5. Hashing

### 6. Collision and Collision Resolution Techniques
- Introduction to Collision
- Collision Resolution Techniques:
  - Open Hashing (Chaining)
  - Closed Hashing (Probing)

## 🎯 Learning Goals

By the end of this module, I aim to:
- Understand the purpose of sorting and searching.
- Differentiate between internal and external sorting.
- Understand and perform selection sort and bubble sort.
- Work through merge sort and quick sort using examples.
- Understand linear and binary searching.
- Write algorithms for searching techniques.
- Understand hashing, hash tables, and hash functions.
- Learn how collisions occur and how they can be resolved.
