# Module 3: Non-Linear Data Structures

So far, we've been dealing with linear data structures, where elements are organised sequentially.

Now we're moving into non-linear data structures, specifically **Trees and Graphs**.

This module covers how data can be organised in hierarchical and interconnected ways. There's terminology, properties, representations, traversals, and quite a few things to understand before everything starts making sense.

Let's get into it.

## 📖 Topics Covered

### 1. Introduction to Trees
- Definition of Trees
- Basic Tree Terminology
- Types of Binary Trees:
  - Complete Binary Tree
  - Full Binary Tree
  - Skewed Binary Tree
  - Expression Tree
- Properties of Binary Trees
- Applications of Trees

### 2. Binary Tree Representation
- Array Representation
- Linked List Representation

### 3. Binary Tree Operations
- Insertion
- Deletion
- Tree Traversal:
  - Inorder Traversal
  - Preorder Traversal
  - Postorder Traversal
- Traversal Concepts with Examples
- Non-Recursive Binary Tree Traversal Algorithms

### 4. Introduction to Graphs
- Definition of Graphs
- Basic Graph Terminology
- Types of Graphs:
  - Directed Graph
  - Undirected Graph
  - Weighted Graph

### 5. Graph Representation
- Adjacency Matrix
- Adjacency List
- Applications of Graphs

## 🎯 Learning Goals

By the end of this module, I aim to:
- Understand the basic concepts and terminology of trees.
- Identify different types of binary trees.
- Understand the properties and applications of binary trees.
- Learn different ways of representing binary trees.
- Understand insertion, deletion, and traversal operations.
- Learn the different traversal techniques and their algorithms.
- Understand graphs, their types, representations, and applications.
