# 3.7 Graphs

## What is a Graph?

A graph is a **non-linear data structure** consisting of **vertices** and **edges** that connect these vertices.

A graph is written as **G = (V, E)**, made up of two sets, **V** and **E**, where:

- **V** is the **set of nodes** (also called vertices)
- **E** is the **set of edges**, each identified with a **unique pair of nodes** in V

```
      A
     / \
    B───C───D          E

V = { A, B, C, D, E }
E = { (A,B), (A,C), (B,C), (C,D) }
```

> **Real-life examples:** a map (cities are nodes, roads are edges), a social network (people are nodes, friendships are edges), an airline network (airports are nodes, flights are edges).

> **Tree vs graph:** a tree is a special kind of graph. It's **connected** and has **no cycles**. A general graph can have cycles, loops, and even separate pieces.

## Graph Terminologies

We'll use the graph above for the examples.

### Endpoints

Let **e = (u, v)**. Then the nodes **u and v** are referred to as the **endpoints** of e.

Example: for the edge `(A, B)`, the endpoints are A and B. We also say A and B are **adjacent** (neighbours), because an edge joins them.

### Degree

The **number of edges containing u** is the **degree** of node u.

| Node | A | B | C | D | E |
|------|---|---|---|---|---|
| **Degree** | 2 | 2 | 3 | 1 | 0 |

> If you add up all the degrees, you get **twice the number of edges** (every edge has two ends). Here: `2 + 2 + 3 + 1 + 0 = 8 = 2 × 4 edges` ✓

### Isolated node

If **u does not belong to any edge** (its degree is 0), then u is called an **isolated node**.

Example: `E` is isolated. No edge touches it.

### Path

A **finite sequence of edges that connects a series of vertices** is called a **path**.

Example: `A → B → C → D` is a path.

### Length of a path

The **number of edges in a path** is the **length** of the path.

Example: `A → B → C → D` uses 3 edges, so its length is **3**.

### Closed path

A path is said to be **closed** if it **starts and ends at the same node**.

Example: `A → B → C → A` is a closed path.

### Simple path

A path is considered to be **simple** if **all its nodes are distinct**, except that the **initial and last node** may be the same.

Example: `A → B → C → D` is simple (no node repeats). `A → B → C → A` is also simple, because the only repeat is the first and last node.

Not simple: `A → B → C → A → C → D`, because A and C appear more than once in the middle.

### Cycle

A **cycle** is a **closed simple path** with a **length of 3 or more**.

> The missing word in your notes is **closed**: a cycle is a *closed* simple path of length 3 or more.

Example: `A → B → C → A` is a cycle of length 3.

```
      A
     / \        A → B → C → A  is a cycle
    B───C
```

### Connected graph

A graph is considered to be **connected** if and only if **any two of its nodes have a path between them**.

Our example graph is **not connected**, because `E` has no path to any other node. If we remove `E`, the rest is connected.

### Complete graph

If **every node u in a graph is adjacent to every other node v** in the graph, then the graph is said to be **complete**.

```
   A───B
   │╲ ╱│          A complete graph with 4 nodes
   │ ╳ │          Every node is joined to every other node
   │╱ ╲│
   C───D
```

> **Extra:** a complete graph with `n` nodes has `n(n − 1) / 2` edges. For 4 nodes: `4 × 3 / 2 = 6` edges ✓

### Loop

An edge **E** is called a **loop** if it has **identical endpoints**, that is, **E = (v, v)**. It's an edge that starts and ends at the same node.

```
   ⟲
   A        a loop at A: the edge (A, A)
```

### Parallel edges

When **multiple edges in a graph connect the same pair of nodes**, those edges are called **parallel edges**.

```
   A ══════ B        two edges between A and B
```

## Quick Revision

| Term | Meaning |
|------|---------|
| **Graph** | G = (V, E), a set of vertices and a set of edges |
| **Endpoints** | The two nodes u and v of an edge e = (u, v) |
| **Degree** | Number of edges containing a node |
| **Isolated node** | A node with degree 0 |
| **Path** | Sequence of edges connecting a series of vertices |
| **Length of path** | Number of edges in the path |
| **Closed path** | Starts and ends at the same node |
| **Simple path** | All nodes distinct (except the first and last may match) |
| **Cycle** | A closed simple path of length 3 or more |
| **Connected graph** | A path exists between any two nodes |
| **Complete graph** | Every node is adjacent to every other node |
| **Loop** | An edge with identical endpoints, e = (v, v) |
| **Parallel edges** | Multiple edges connecting the same pair of nodes |
