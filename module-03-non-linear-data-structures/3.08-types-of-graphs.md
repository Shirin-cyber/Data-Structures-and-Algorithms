# 3.8 Types of Graphs

There are **3 types** of graphs:

```
Types of Graphs
├── 1. Undirected Graph
├── 2. Directed Graph
└── 3. Weighted Graph
```

---

# 1. Undirected Graph

A graph with edges that **don't have direction** is called an **undirected graph**.

The edges in an undirected graph indicate a **two-way relationship**. So the edge `(u, v)` is the same as `(v, u)`, and you can travel along it in **both directions**.

```
      A
     / \
    B───C───D
```

> **Real-life examples:** a friendship on Facebook (if A is B's friend, B is A's friend), a two-way road.

---

# 2. Directed Graph

A directed graph is a graph that has edges **with direction**. These edges represent a **one-way relationship**, that is, an edge can be traversed **in only one direction**.

```
         A
        ╱ ╲
       ▼   ▼
       B ──► C ──► D
```

Edges: `A → B`, `A → C`, `B → C`, `C → D`

> **Real-life examples:** a one-way street, following someone on Instagram (you can follow them without them following you), links between web pages.

> **Note:** in a directed graph, `(u, v)` is **not** the same as `(v, u)`.

## Terms for a directed graph

If a graph has an edge **e = (u, v)**, then:

- e **begins at u** and **ends at v**
- **u** is the **origin** and **v** is the **destination** (or **terminal point**)
- The number of edges **beginning at** a node is its **outdegree**.
- The number of edges that **end at** a node is its **indegree**.
- If a node has a **positive outdegree but 0 indegree**, it is called a **source**.
- If a node has **0 outdegree and a positive indegree**, it is called a **sink**.
- If there is a **directed path from u to v**, then node **v** is said to be **reachable from u**.

### Example

Using the directed graph above:

| Node | Outdegree | Indegree | Type |
|------|-----------|----------|------|
| **A** | 2 | 0 | **Source** (edges only leave it) |
| **B** | 1 | 1 | |
| **C** | 1 | 2 | |
| **D** | 0 | 1 | **Sink** (edges only enter it) |

- **D is reachable from A**, because there's a directed path `A → C → D`.
- **A is not reachable from D**, because the edges only go one way.

> The total of all indegrees = the total of all outdegrees = the **number of edges**. Here: `0+1+2+1 = 4` and `2+1+1+0 = 4`, and there are 4 edges ✓

---

# 3. Weighted Graph

A weighted graph is a graph that has a **number associated with each of its edges**. This number is called the **weight** (or cost) of the edge.

A weighted graph can be a **directed or an undirected** graph.

```
          5
     A ────── B
      ╲      ╱
     2 ╲    ╱ 1
        ╲  ╱
         C
```

Here the edge `A–B` has weight 5, `A–C` has weight 2, and `B–C` has weight 1.

The weight can mean different things:

- the **distance** between two places
- the **time** or **cost** of travelling between them
- the **speed** or **capacity** of a connection

> **Real-life example:** Google Maps. Places are nodes, roads are edges, and the weight is the distance or travel time. Finding the **shortest path** means finding the route with the smallest total weight.

---

## Comparing the Three

| | Undirected | Directed | Weighted |
|---|-----------|----------|----------|
| **Edges have direction?** | No | Yes | Can be either |
| **Edges have a number?** | No | No | Yes |
| **Relationship** | Two-way | One-way | Edge has a cost or value |
| **Example** | Friendship | One-way street | Road map with distances |

> **Good to know:** "directed or undirected" and "weighted or not" are **two separate ways** of describing a graph. So a graph can be, for example, **directed and weighted** (one-way roads with distances).

---

## Quick Revision

- **Undirected graph:** edges have no direction, a two-way relationship.
- **Directed graph:** edges have direction, a one-way relationship. For e = (u, v), u is the origin and v is the destination.
- **Outdegree:** edges beginning at a node. **Indegree:** edges ending at a node.
- **Source:** outdegree positive, indegree 0. **Sink:** outdegree 0, indegree positive.
- **Reachable:** v is reachable from u if there's a directed path from u to v.
- **Weighted graph:** each edge has a number (weight). It can be directed or undirected.
