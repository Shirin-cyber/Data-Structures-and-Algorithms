# 3.1 Introduction to Trees

*Module 3: Non-Linear Data Structures*

In a **linear** data structure (array, linked list, stack, queue), the elements form a sequence. In a **non-linear** data structure, the elements are **not arranged in a sequence**. The two main non-linear data structures are **trees** and **graphs**.

---

## What is a Tree?

A tree is a **non-linear data structure** that organizes data in a **hierarchical structure**. It has a **recursive definition**:

> A tree is a set of **one or more nodes** with one node identified as the tree's **root**, and all the remaining nodes **partitionable** into non-empty sets, each of which is a **subtree** of the root.

In simple words: a tree is a root plus smaller trees (subtrees) hanging under it, and each of those subtrees is itself a tree. That's why the definition is recursive.

Since it's a non-linear data structure, different kinds of trees can provide **faster and easier access** to the data (for example, searching in a balanced binary search tree is much quicker than going through a list one by one).

> **Real-life examples:** the folder structure on a computer, a family tree, a company's org chart.

### Example tree used in these notes

```
              A              ← Level 0 (Root)
            /   \
           B     C           ← Level 1
          / \     \
         D   E     F         ← Level 2
            /
           G                 ← Level 3
```

## Basic Tree Terminologies

| Term | Meaning | In the example tree |
|------|---------|---------------------|
| **Node** | A unit that contains a key or value as well as pointers to its child nodes | A, B, C, D, E, F, G |
| **Edge** | The connecting link between two nodes | A–B, A–C, B–D, B–E, C–F, E–G |
| **Root** | The topmost node in a tree. This is where the tree originates from | A |
| **Parent node** | A node that has a branch from it to another node | A is the parent of B and C |
| **Child node** | A node that is a direct descendant of another node (it comes directly below it) | B and C are children of A |
| **Sibling node** | Nodes that have the same parent | B and C. Also D and E |
| **Leaf node** | A node that doesn't have any child node. Also called a **terminal node** | D, F, G |
| **Internal node** | A node having at least one child | A, B, C, E |
| **Level** | Each step from top to bottom is referred to as a level of the tree | A is on level 0, B and C on level 1, and so on |

> **Note on levels:** here the root is counted as **level 0**. Some books start counting from level 1. Follow whatever your syllabus uses.

### Degree

- The **degree of a node** is the **total number of children** of that node.
- **Indegree:** the number of edges **arriving** at a node.
- **Outdegree:** the number of edges **leaving** that node.

In a tree, every node has indegree 1 (one edge from its parent), except the root, which has indegree 0. The outdegree of a node is the same as its degree.

| Node | A | B | C | D | E | F | G |
|------|---|---|---|---|---|---|---|
| **Degree (outdegree)** | 2 | 2 | 1 | 0 | 1 | 0 | 0 |
| **Indegree** | 0 | 1 | 1 | 1 | 1 | 1 | 1 |

> The degree of the **whole tree** is the highest degree among its nodes. Here it's 2.

### Depth

The **depth** of a node is the **total number of edges from the root node to that particular node**.

- Depth of A (root) = 0
- Depth of B = 1
- Depth of E = 2
- Depth of G = 3

### Height

The **height of a node** is the **total number of edges that lie on the longest path from the node down to any leaf node**.

The **height of the tree** is the **height of the root node**.

- Height of G (a leaf) = 0
- Height of E = 1 (E → G)
- Height of B = 2 (B → E → G)
- Height of A = 3 (A → B → E → G), so the **height of the tree is 3**

> **Depth vs Height:** depth is counted **from the root down to the node**. Height is counted **from the node down to its deepest leaf**.

## All Values for the Example Tree

| Node | Level | Depth | Height | Degree |
|------|-------|-------|--------|--------|
| A | 0 | 0 | 3 | 2 |
| B | 1 | 1 | 2 | 2 |
| C | 1 | 1 | 1 | 1 |
| D | 2 | 2 | 0 | 0 |
| E | 2 | 2 | 1 | 1 |
| F | 2 | 2 | 0 | 0 |
| G | 3 | 3 | 0 | 0 |

> A tree with `n` nodes always has exactly `n - 1` edges. Here, 7 nodes and 6 edges.

---

## Quick Revision

- A **tree** is a non-linear, hierarchical data structure with a recursive definition: a root plus subtrees.
- **Root:** topmost node. **Leaf:** no children. **Internal node:** at least one child.
- **Parent / child / sibling:** a node directly above, directly below, and on the same level under the same parent.
- **Degree:** number of children of a node. **Indegree:** edges arriving. **Outdegree:** edges leaving.
- **Depth:** edges from the root to the node. **Height:** edges on the longest path from the node to a leaf.
- **Height of the tree** = height of the root.
