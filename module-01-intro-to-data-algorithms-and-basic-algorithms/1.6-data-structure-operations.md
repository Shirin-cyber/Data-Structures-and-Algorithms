# 1.6 Data Structure Operations

Whatever data structure we use, we mostly do the same basic things with the data. These are the main operations:

```
Data Structure Operations
├── Traversing
├── Searching
├── Insertion
├── Deletion
├── Sort
└── Merging
```

---

## a. Traversing

**Visiting each node** (or element) so that the items in it can be accessed.

Traversing means going through the whole structure once, one element at a time. It's used for printing all the elements, counting them, or adding them up.

```c
for (int i = 0; i < n; i++) {
    printf("%d ", arr[i]);   // visit every element once
}
```

## b. Searching

Finding the **location of the record with a given key or value**.

Example: in the array `{10, 20, 30, 40}`, searching for `30` gives the location (index) `2`.

If the value isn't there, the search is **unsuccessful**.

> **Extra point:** two common ways to search are **linear search** (check one by one) and **binary search** (repeatedly halve a *sorted* list).

## c. Insertion

**Adding a new record** to the structure.

Example: insert `25` into `{10, 20, 30, 40}` at position 2:

```
Before:  10  20  30  40
After:   10  20  25  30  40
```

In an array, elements after that position have to be **shifted** to make space. In a linked list, only the links change.

## d. Deletion

**Removing a record** from the structure.

Example: delete `20` from `{10, 20, 30, 40}`:

```
Before:  10  20  30  40
After:   10  30  40
```

In an array, the elements after the removed one are shifted to fill the gap.

## e. Sort

**Arranging records in logical / numerical order**, like ascending or descending numbers, or alphabetical order for names.

```
Before:  40  10  30  20
After:   10  20  30  40
```

## f. Merging

**Combining records from two different sorted files into a single file.**

```
List 1:   1   3   5
List 2:   2   4   6
Merged:   1   2   3   4   5   6   (still sorted)
```

---

## How these connect to what we've learned

- **PUSH** and **POP** in a stack are just insertion and deletion, restricted to one end (the TOP).
- Queue operations are insertion at the Rear and deletion at the Front.
- Searching and sorting get a lot easier or harder depending on the structure you pick, which is why choosing the right data structure matters.
