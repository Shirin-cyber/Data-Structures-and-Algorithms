# Data Types

## What is a Data Type?

A **data type** tells the computer **what kind of value** a variable can hold, and **what operations** can be done on it.

It decides three things:

1. **The kind of values** allowed (whole numbers, decimals, characters, etc.)
2. **How much memory** the value takes
3. **What operations** make sense on it (you can add two numbers, but you can't "add" two characters in a meaningful way)

Example:

```c
int age = 20;        // whole number
float height = 5.9;  // decimal number
char grade = 'A';    // single character
```

> The examples in these notes use C syntax. The idea is the same in other languages, but sizes and names can differ a bit.

---

## Why do we need data types?

- The computer needs to know **how much memory to set aside** for a value.
- It stops mistakes, like storing text in a variable meant for numbers.
- It tells the compiler **how to read** the bits stored in memory. The same bits can mean a number or a character depending on the type.

---

## Quick Revision

- A **data type** defines the kind of value, its memory size, and the operations allowed.
- Sizes depend on the compiler and system.
- A data type describes a **single value's kind**, while a data structure organizes a **collection** of data.
