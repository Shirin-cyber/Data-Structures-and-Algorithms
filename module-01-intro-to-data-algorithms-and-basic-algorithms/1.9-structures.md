# 1.9 Structures

## What is a Structure?

A structure is a **user defined data type in C** that **groups variables of different data types under a common name**. It is used to represent a **record** containing related information.

For example, a student record has a name (text), a roll number (integer) and marks (decimal). These are different types, and an array can't hold them together because an array only holds the **same** type. A structure can.

The keyword used to declare a structure is **`struct`**.

---

## Syntax for Declaring a Structure

```c
struct structurename
{
    datatype variable1;
    datatype variable2;
    .......
    datatype variableN;
};
```

> **Note:** there's **no semicolon after the structure name**. The semicolon goes only at the **end**, after the closing brace `}`. Writing `struct structurename;` followed by `{` is a syntax error.

### Example

```c
struct Student
{
    int roll;
    char name[20];
    float marks;
};
```

This only **defines** the structure (like a blueprint). No memory is used until we create a variable of it.

### Creating variables and accessing members

```c
struct Student s1;           // create a variable of type struct Student

s1.roll = 101;               // use the dot (.) operator to reach a member
s1.marks = 87.5;
strcpy(s1.name, "Asha");     // for strings, use strcpy() (needs <string.h>)

printf("%d", s1.roll);       // prints 101
```

- The **dot operator (`.`)** is used to access members through a normal structure variable.
- If you have a **pointer** to a structure, use the **arrow operator (`->`)** instead:

```c
struct Student *p = &s1;
printf("%d", p->roll);
```

### Memory of a structure

Each member gets its **own memory**, so the size of a structure is about the **sum of its members' sizes** (it can be a bit more because of padding added by the compiler).

---

## Self Referential Structure

A self referential structure is a structure that **contains a pointer to another variable of the same structure type**.

It is mainly used to build data structures such as **linked list, stack, queue**, etc.

### Syntax

```c
struct node
{
    int data;
    struct node *next;
};
```

Here, `next` is a pointer that can store the address of **another `struct node`**. This is how nodes get connected one after another:

```
 ┌──────┬──────┐    ┌──────┬──────┐    ┌──────┬──────┐
 │ data │ next │ ─► │ data │ next │ ─► │ data │ NULL │
 └──────┴──────┘    └──────┴──────┘    └──────┴──────┘
   struct node         struct node         struct node
```

> **Why a pointer and not the structure itself?** A structure can't contain a full copy of itself, because it would need infinite memory. But it can contain a **pointer** to one, since a pointer is just an address and always has a fixed size.

This is the same node structure we used for the linked list in 1.4. The `data` part holds the value, and `next` is the link part holding the address of the next node.

---

## Quick Revision

- A **structure** is a user defined data type in C that groups variables of **different data types** under one name.
- It represents a **record** with related information.
- Declared with the keyword **`struct`**, with the semicolon after the closing brace.
- Members are accessed with the **dot operator (`.`)**, or the **arrow operator (`->`)** through a pointer.
- A **self referential structure** contains a **pointer to the same structure type**.
- It's mainly used to build linked lists, stacks, queues, etc.
