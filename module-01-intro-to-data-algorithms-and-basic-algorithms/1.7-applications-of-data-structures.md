# 1.7 Applications of Data Structures

Each data structure is good at certain jobs. Here's where each one is used.

---

## a. Array

- To implement **mathematical vectors and matrices**
- To model **sets or collections** in computer programming
- To implement **other data structures**

An array is the base for a lot of other structures. Stacks, queues and many others can be built on top of one. Because elements sit in continuous memory and can be reached by index, arrays are great when you need fast access.

---

## b. Linked List

- To implement **other data structures** such as queue, stack, tree, etc.
- Used for **dynamic memory allocation**
- For **manipulating polynomials** and **representing sparse matrices**
- A **doubly linked list** can be used in **navigation systems**

Some more detail:

- **Dynamic memory allocation:** memory is handed out and taken back as the program runs, and linked lists are a natural fit for keeping track of those blocks.
- **Polynomials:** each term (coefficient and power) can be stored in one node, so `3x² + 5x + 2` becomes three nodes.
- **Navigation systems:** a doubly linked list lets you move to the next *and* the previous item, like going forward and back between locations. Browser back/forward buttons and music playlists work in a similar way.

---

## c. Trees

- To **search for an element** in a **Binary Search Tree (BST)**
- A computer uses a **syntax tree** to **parse the program** you write
- **Shortest path trees** and **spanning trees** are used in **bridges and routers**

Some more detail:

- **BST:** the tree is arranged so that searching is quick, because each comparison lets you ignore a big part of the tree.
- **Syntax tree:** when you write code, the compiler breaks it into a tree to understand its structure before running it.
- **Bridges and routers:** spanning trees help network bridges avoid loops, and shortest path trees help routers pick the best route for data.

> **Extra examples:** the folder structure on your computer and a family tree are also trees.

---

## d. Stack

- **Evaluating expressions**
- **Conversion between expressions**
- **Backtracking**
- **Parsing context-free languages**
- **Recursion removal**
- **Tree and graph traversal**

Some more detail:

- **Evaluating expressions:** postfix expressions like `2 3 +` are evaluated using a stack.
- **Conversion between expressions:** converting infix (`a + b`) to postfix (`a b +`) or prefix.
- **Backtracking:** going back to a previous step when you hit a dead end, like solving a maze or the undo feature in an editor.
- **Parsing context-free languages:** compilers use stacks to check things like whether brackets are balanced.
- **Recursion removal:** function calls already use a stack internally. A recursive program can be rewritten without recursion by using a stack of our own.
- **Tree and graph traversal:** depth-first traversal uses a stack to remember where to go back to.

---

## e. Queue

- Manage **resource sharing** such as **CPU scheduling**, **disk scheduling**, etc.

Whatever request comes first gets served first, which keeps sharing fair.

> **Extra examples:** a printer queue, and breadth-first traversal of trees and graphs.

---

## f. Graph

- **Transportation networks** like Google Maps
- Finding the **shortest path**
- **Airline networks**
- **Social networks**

Some more detail:

- In a map, places are the **vertices** and roads are the **edges**.
- In a social network, people are the vertices and friendships or follows are the edges.
- Finding the shortest path between two places in a map or airline network is a classic graph problem.

---

## Quick Revision

| Data Structure | Common Uses |
|----------------|-------------|
| **Array** | Vectors and matrices, sets and collections, building other data structures |
| **Linked List** | Building stack, queue and tree, dynamic memory allocation, polynomials, sparse matrices, navigation (doubly) |
| **Tree** | BST searching, syntax trees for parsing, spanning and shortest path trees in bridges and routers |
| **Stack** | Expression evaluation and conversion, backtracking, parsing, recursion removal, tree and graph traversal |
| **Queue** | Resource sharing like CPU and disk scheduling |
| **Graph** | Transportation networks, shortest path, airline networks, social networks |
