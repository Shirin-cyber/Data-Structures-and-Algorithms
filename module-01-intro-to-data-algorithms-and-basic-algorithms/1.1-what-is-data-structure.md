# 1.1 What is Data Structure?

## Data

**Data** is a single unit of value. On its own it's just a raw fact: a number, a character, a word. It doesn't mean much until we put it in some context.

Examples: `25`, `"Ravi"`, `'A'`, `98.6`

> **Data vs Information:** `25` is data. "Ravi is 25 years old" is information. Information is data that has been processed or given meaning.

---

## Group Items

Data items can be divided into smaller sub-items. These are called **Group Items**.

- **Group item:** can be broken down into smaller parts.
  - Example: `Name` → `First Name`, `Middle Name`, `Last Name`
  - Example: `Address` → `House No`, `Street`, `City`, `PIN`
- **Elementary item:** can't be broken down any further.
  - Example: `Roll Number`, `Age`, `Gender`

So the idea is: some data is a single piece (elementary), and some data is made of several pieces (group).

```
Student (group item)
├── Name (group item)
│   ├── First Name   (elementary)
│   └── Last Name    (elementary)
├── Roll No          (elementary)
└── Age              (elementary)
```

## Related Terms (good to know)

These show up a lot when data is organized, so they're useful for exams:

| Term | Meaning | Example |
|------|---------|---------|
| **Entity** | Something that has data stored about it | A student, an employee |
| **Attribute** | A property of the entity | Name, Roll No, Age |
| **Entity set** | A collection of similar entities | All students in a class |
| **Field** | A single unit of stored data | `Roll No` |
| **Record** | A collection of related fields | One student's full details |
| **File** | A collection of related records | The whole class's records |

## Data Structure

A **Data Structure** is a collection of data elements that provides an efficient way of storing and organizing data in a computer, so that it can be **used efficiently**.

Another way to define it:

> The **logical or mathematical model** of a particular organization of data is called a data structure.

### Breaking the definition down

- **Collection of data elements:** it's not just one value, it's a group of values arranged in some way.
- **Storing and organizing:** it decides *where* and *how* data is kept in memory.
- **Efficiently:** the whole point is to save time (fast access, search, update) and space (memory).
- **Logical or mathematical model:** it's the *idea* of how data is arranged and how the elements relate to each other, separate from how it's actually written in code or placed in memory.

### Why do we need data structures?

- Real programs handle huge amounts of data, and storing it randomly makes it slow to use.
- The right structure makes **searching, inserting, and deleting** much faster.
- It helps use **memory** properly.
- It makes code cleaner and easier to maintain.

**Real-life comparison:** A dictionary is sorted alphabetically so you can find a word quickly. If the words were in random order, you'd have to read the whole thing. The alphabetical order is the "structure" that makes searching efficient.

## Quick Revision

- **Data** = a single unit of value.
- **Group items** = data that can be divided into sub-items. **Elementary items** can't be divided.
- **Data structure** = a way of storing and organizing data so it can be used efficiently.
- It's also defined as the **logical or mathematical model** of a particular organization of data.
- Main goal: **efficiency** in time and memory.
