# Stack

## What's a Stack?

A stack is a **linear data structure** in which an element may be inserted and deleted **only at one end**, called the **TOP** of the stack.

That means elements are removed from the stack in the **reverse order of insertion**. So stacks are also called **Last In First Out (LIFO)** lists.

```
        │  30  │  ◄── TOP (last one in, first one out)
        │  20  │
        │  10  │
        └──────┘
```

> **Real-life example:** a pile of plates. You put a new plate on top, and you take a plate from the top. You can't pull one from the middle without moving the others.

---

## Basic Operations on Stack

| Operation | What it does |
|-----------|--------------|
| **a. PUSH** | Inserting an element in a stack |
| **b. POP** | Deleting an element from the stack |
| **c. PEEK** | Returns the topmost element of the stack |

> **Extra:** two helper checks are also common, **isEmpty** (is the stack empty?) and **isFull** (is the stack full?).

---

## PUSH Operation

Inserting a new element on the top of the stack is called the **PUSH** operation.

After the PUSH operation, the **TOP will point to the newly inserted item**.

```
Before PUSH(40):        After PUSH(40):

   │  30  │ ◄─ TOP        │  40  │ ◄─ TOP
   │  20  │               │  30  │
   │  10  │               │  20  │
   └──────┘               │  10  │
                          └──────┘
```

### Stack Overflow

A **stack overflow** occurs when a new element is pushed onto a stack that is **already full**.

Since the stack has reached its **maximum storage capacity**, no further insertion is possible, and trying to do so results in an **overflow condition**.

### Values of TOP

If the stack can hold `n` elements (array indexes `0` to `n-1`):

| Value of TOP | Meaning |
|--------------|---------|
| `TOP = n-1` | The stack is **full** |
| `TOP = 0` | The stack has **only one element** |
| `TOP = -1` | The stack is **empty** |

### Algorithm for PUSH

Here, `MAX` is the maximum size of the stack and `ITEM` is the element to be pushed.

```
Step 1: Start
Step 2: Check if the stack is full
          If TOP = MAX - 1, then
              Print "Stack overflow"
              Go to Step 6
Step 3: Else
          Increment TOP by 1
          TOP = TOP + 1
Step 4: STACK[TOP] = ITEM
Step 5: Print "Item inserted successfully"
Step 6: Stop
```

## POP Operation

The **POP** operation deletes an element from the **top** of the stack.

The value of **TOP is decremented by 1** after the POP operation.

```
Before POP:             After POP:

   │  40  │ ◄─ TOP        │  30  │ ◄─ TOP
   │  30  │               │  20  │
   │  20  │               │  10  │
   │  10  │               └──────┘
   └──────┘             (40 is removed)
```

### Stack Underflow

A **stack underflow** occurs when an attempt is made to remove an element from a stack that is **already empty**.

Since a stack follows the **Last In First Out (LIFO)** principle, elements are removed from the TOP. If the stack contains no elements and a POP operation is performed, it leads to an **underflow condition**.

### Algorithm for POP

```
Step 1: Start
Step 2: Check if the stack is empty
          If TOP = -1, then
              Print "Stack underflow"
              Go to Step 4
Step 3: Set ITEM = STACK[TOP]
          Decrement TOP by 1
          TOP = TOP - 1
          Print "ITEM deleted successfully"
Step 4: Stop
```

---

## PEEK Operation 

**PEEK** returns the topmost element of the stack **without removing it**. TOP stays where it is.

```
Step 1: Start
Step 2: If TOP = -1, then
            Print "Stack is empty"
        Else
            Return STACK[TOP]
Step 3: Stop
```

---

## Overflow vs Underflow

| | Stack Overflow | Stack Underflow |
|---|----------------|-----------------|
| **When it happens** | PUSH on a **full** stack | POP on an **empty** stack |
| **Condition** | `TOP = MAX - 1` | `TOP = -1` |

## Stack in C (array implementation)

```c
#include <stdio.h>
#define MAX 5

int stack[MAX];
int top = -1;                          // -1 means the stack is empty

void push(int item) {
    if (top == MAX - 1) {              // full?
        printf("Stack overflow\n");
        return;
    }
    top = top + 1;
    stack[top] = item;
    printf("Item inserted successfully\n");
}

void pop() {
    if (top == -1) {                   // empty?
        printf("Stack underflow\n");
        return;
    }
    int item = stack[top];
    top = top - 1;
    printf("%d deleted successfully\n", item);
}

int peek() {
    if (top == -1) {
        printf("Stack is empty\n");
        return -1;
    }
    return stack[top];
}
```

### Quick trace

Say `MAX = 4`, starting with an empty stack (`TOP = -1`):

| Operation | Stack (bottom → top) | TOP |
|-----------|----------------------|-----|
| `push(10)` | 10 | 0 |
| `push(20)` | 10, 20 | 1 |
| `push(30)` | 10, 20, 30 | 2 |
| `pop()` | 10, 20 *(30 removed)* | 1 |
| `peek()` | 10, 20 *(returns 20)* | 1 |

---

## Quick Revision

- A **stack** is a linear data structure where insertion and deletion happen only at one end, the **TOP**.
- It follows **LIFO**: the last element in is the first one out.
- **PUSH** inserts, **POP** deletes, **PEEK** returns the top element.
- **Overflow:** pushing onto a full stack (`TOP = MAX - 1`).
- **Underflow:** popping from an empty stack (`TOP = -1`).
- After PUSH, TOP goes **up by 1**. After POP, TOP goes **down by 1**.
