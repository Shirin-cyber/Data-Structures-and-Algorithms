# 1. Circular Queue

A circular queue is a **special type of queue** where the **last element is connected back to the first element**, forming a circle. In a circular queue, the **first index comes right after the last index**.

```
Index:     0     1     2     3     4
        ┌─────┬─────┬─────┬─────┬─────┐
        │     │     │ 30  │ 40  │ 50  │
        └─────┴─────┴─────┴─────┴─────┘
           ▲                       │
           └───── after 4 comes 0 ─┘
```

### Why do we need it?

In a normal (linear) queue, the free spaces before FRONT are never reused. After some dequeues, REAR can reach `MAX - 1` and the queue says "overflow" even though there's empty space at the start. A circular queue fixes this by letting REAR **wrap around** to index `0` and reuse that space.

### How the wrap-around works 

Instead of `REAR = REAR + 1`, a circular queue uses:

```
REAR  = (REAR  + 1) % MAX
FRONT = (FRONT + 1) % MAX
```

Example with `MAX = 5`: if `REAR = 4`, then `(4 + 1) % 5 = 0`, so REAR goes back to index 0.

```
Before enqueue(60):  index 0 is empty, REAR = 4
After  enqueue(60):  REAR = (4 + 1) % 5 = 0, and QUEUE[0] = 60
```

### Conditions

| State | Condition |
|-------|-----------|
| **Empty** | `FRONT = -1` |
| **Full** | `(REAR + 1) % MAX = FRONT` |

### Algorithm for Enqueue (circular queue)

```
Step 1: Start
Step 2: If (REAR + 1) % MAX = FRONT
          Print "Queue overflow"
          Go to Step 5
Step 3: If FRONT = -1
          Set FRONT = REAR = 0
        Else
          Set REAR = (REAR + 1) % MAX
Step 4: Set QUEUE[REAR] = ITEM
Step 5: Stop
```

### Algorithm for Dequeue (circular queue) 

```
Step 1: Start
Step 2: If FRONT = -1
          Print "Queue underflow"
          Go to Step 5
Step 3: Set ITEM = QUEUE[FRONT]
Step 4: If FRONT = REAR
          Set FRONT = REAR = -1
        Else
          Set FRONT = (FRONT + 1) % MAX
Step 5: Stop
```

# 2. Double Ended Queue (Deque)

A double ended queue is a **generalized version of the queue** data structure that allows **INSERT and DELETE at both ends**.

```
   Insert / Delete                                Insert / Delete
         ◄──►   ┌──────┬──────┬──────┬──────┐   ◄──►
      (front)   │  10  │  20  │  30  │  40  │   (rear)
                └──────┴──────┴──────┴──────┘
```

A double ended queue can act as **both a stack and a queue**. It is useful in many problems where we need only a **subset of all the operations**, like INSERT, REMOVE, etc.

### Operations

| Operation | What it does |
|-----------|--------------|
| **Insert at front** | Adds an element at the front |
| **Insert at rear** | Adds an element at the rear |
| **Delete from front** | Removes the element at the front |
| **Delete from rear** | Removes the element at the rear |

### How it acts as a stack or a queue 

- **As a stack (LIFO):** insert and delete at the **same end** only.
- **As a queue (FIFO):** insert at the **rear** and delete from the **front**.

### Variations

| Type | Rule |
|------|------|
| **Input restricted deque** | Insertion at **one end** only, deletion at both ends |
| **Output restricted deque** | Deletion at **one end** only, insertion at both ends |

# Quick Revision

- **Circular queue:** the last element is connected back to the first, so the first index comes right after the last index. It reuses free space that a linear queue wastes.
- **Double ended queue (deque):** allows INSERT and DELETE at **both ends**, and can act as both a **stack** and a **queue**.
