# Queue

## What's a Queue?

A queue is a **linear data structure** in which:

- **Deletions** can only occur at one end, known as **FRONT**
- **Insertions** can only occur at the other end, known as **REAR**

A queue follows the **First In First Out (FIFO)** principle. The element that went in first is the first one to come out.

```
   FRONT                                  REAR
     ▼                                      ▼
  ┌──────┬──────┬──────┬──────┬──────┐
  │  10  │  20  │  30  │  40  │      │ ◄── Enqueue (insert here)
  └──────┴──────┴──────┴──────┴──────┘
     │
     ▼
  Dequeue (delete from here)
```

> **Real-life example:** a line at a ticket counter. The first person to join is the first one served. New people join at the back.

---

## Basic Operations

| Operation | What it does |
|-----------|--------------|
| **a. Enqueue** | Add a new element to the **end** of the queue |
| **b. Dequeue** | Remove an element from the **front** of the queue |

---

## Front and Rear

**FRONT** and **REAR** indicate the positions where **deletion** and **insertion** can be performed.

**Initially, the values of FRONT and REAR are set to `-1`.**

| State of queue | FRONT | REAR |
|----------------|-------|------|
| Empty (at the start) | `-1` | `-1` |
| Just one element inserted | `0` | `0` |
| Full (cannot enqueue any more) | | `MAX - 1` |

---

## Enqueue Operation

Inserting a new element into the position pointed to by **REAR** is called the **Enqueue** operation.

- **Check if the queue is full** before inserting.
- After the enqueue operation, **REAR is incremented by 1** and points to the newly inserted element.
- For inserting the **first element** in a queue, the value of **FRONT is set to 0**.

### Queue Overflow

If `REAR = MAX - 1`, the queue is full, and trying to insert gives a **queue overflow**.

### Algorithm for Enqueue

Here `MAX` is the size of the queue and `ITEM` is the element to be inserted.

```
Step 1: Start
Step 2: If REAR = MAX - 1
          Print "Queue overflow"
          Go to Step 5
Step 3: If FRONT = -1 and REAR = -1
          Set FRONT = REAR = 0
        Else
          Set REAR = REAR + 1
Step 4: Set QUEUE[REAR] = ITEM
Step 5: Exit
```

---

## Dequeue Operation

Deleting an element from the position pointed to by **FRONT** is called the **Dequeue** operation.

- **Check if the queue is empty** before deleting.
- After deleting the element, the value of **FRONT is increased by 1**.
- After deleting the **last element**, the queue becomes empty again. FRONT and REAR can be reset to `-1`, the same values they had at the start.

### Queue Underflow

If `FRONT = -1` or `FRONT > REAR`, the queue is empty, and trying to delete gives a **queue underflow**.

### Algorithm for Dequeue

```
Step 1: Start
Step 2: If FRONT = -1 or FRONT > REAR
          Print "Queue underflow"
        Else
          Set ITEM = QUEUE[FRONT]
          Set FRONT = FRONT + 1
Step 3: Exit
```

---

## Quick Trace

Say `MAX = 5`, starting with an empty queue:

| Operation | Queue (front → rear) | FRONT | REAR |
|-----------|----------------------|-------|------|
| *start* | empty | -1 | -1 |
| `enqueue(10)` | 10 | 0 | 0 |
| `enqueue(20)` | 10, 20 | 0 | 1 |
| `enqueue(30)` | 10, 20, 30 | 0 | 2 |
| `dequeue()` | 20, 30 *(10 removed)* | 1 | 2 |
| `dequeue()` | 30 *(20 removed)* | 2 | 2 |
| `dequeue()` | empty *(30 removed)* | 3 | 2 |

In the last row, `FRONT > REAR`, which is exactly the underflow condition, so the queue is empty.

## Queue in C 

```c
#include <stdio.h>
#define MAX 5

int queue[MAX];
int front = -1, rear = -1;

void enqueue(int item) {
    if (rear == MAX - 1) {
        printf("Queue overflow\n");
        return;
    }
    if (front == -1 && rear == -1) {
        front = rear = 0;
    } else {
        rear = rear + 1;
    }
    queue[rear] = item;
}

void dequeue() {
    if (front == -1 || front > rear) {
        printf("Queue underflow\n");
        return;
    }
    int item = queue[front];
    front = front + 1;
    printf("%d deleted\n", item);
}
```

---

## A Limitation of This Queue 

When we dequeue, FRONT moves to the right, but the empty spaces **before FRONT are never reused**. REAR can still reach `MAX - 1`, and then we get "queue overflow" **even though there is free space at the start of the array**.

```
Index:    0     1     2     3     4
        ┌─────┬─────┬─────┬─────┬─────┐
        │  –  │  –  │ 30  │ 40  │ 50  │    REAR = 4 = MAX - 1 → "overflow"
        └─────┴─────┴─────┴─────┴─────┘
        (free, but wasted)
```

This is the main problem with the simple (linear) queue, and the **circular queue** is designed to fix it.

---

## Quick Revision

- A **queue** is a linear data structure that follows **FIFO**.
- **Insertion** happens at the **REAR** (enqueue). **Deletion** happens at the **FRONT** (dequeue).
- Initially, `FRONT = REAR = -1`.
- Inserting the first element sets `FRONT = REAR = 0`. After that, every enqueue does `REAR = REAR + 1`.
- Every dequeue does `FRONT = FRONT + 1`.
- **Overflow:** `REAR = MAX - 1`. **Underflow:** `FRONT = -1` or `FRONT > REAR`.
