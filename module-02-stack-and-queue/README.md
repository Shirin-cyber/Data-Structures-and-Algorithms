# Module 2: Stack and Queue

Module 2 is where we explore two important linear data structures: **Stacks and Queues**.

Both are used to store and organise data, but they follow different rules when it comes to accessing elements.

We'll be looking at their operations, implementations, algorithms, and applications. Time to figure out why adding and removing elements needs so many rules!

## 📖 Topics Covered

### 1. Introduction to Stack
- Definition of Stack
- Stack Operations:
  - Push
  - Pop
  - Peek
  - Display
- Algorithms for Stack Operations

### 2. Applications of Stack
- Recursion
- Infix to Postfix Conversion
- Infix to Postfix Conversion Example and Algorithm

### 3. Implementation of Stack
- Stack Using Array
- Stack Overflow
- Stack Underflow
- Stack Using Linked List
- Algorithms for Implementation

### 4. Introduction to Queue
- Definition of Queue
- Queue Operations:
  - Enqueue
  - Dequeue
  - Peek
  - Display
- Algorithms for Queue Operations

### 5. Types of Queue
- Circular Queue
- Double-Ended Queue (Deque)
  - Input-Restricted Deque
  - Output-Restricted Deque
- Applications of Queue

### 6. Implementation of Queue
- Queue Using Array
- Queue Using Linked List
- Algorithms for Implementation

## 🎯 Learning Goals

By the end of this module, I aim to:
- Understand the working principles of stacks and queues.
- Learn the different operations performed on them.
- Understand stack overflow and underflow.
- Learn how stacks are used in recursion and expression conversion.
- Understand different types of queues.
- Implement stacks and queues using arrays and linked lists.
