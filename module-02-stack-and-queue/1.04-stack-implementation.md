# Implementation of Stack

A stack can be implemented in **two ways**:

1. Using **Arrays**
2. Using **Linked List**

---

# 1. Using Arrays

In this method, a **fixed size array** is used to store the stack elements.

- A variable called **TOP** keeps track of the **index of the topmost element**.
- The **maximum number of elements** the stack can hold is **defined in advance** (called `MAX`).
- The operations are **PUSH** and **POP**.

```
Index:     0     1     2     3     4        MAX = 5
        ┌─────┬─────┬─────┬─────┬─────┐
STACK = │ 10  │ 20  │ 30  │     │     │
        └─────┴─────┴─────┴─────┴─────┘
                      ▲
                     TOP = 2
```

When the stack is empty, `TOP = -1`. When it's full, `TOP = MAX - 1`.

## Algorithm for PUSH (array implementation)

```
Step 1: Start
Step 2: Check if TOP = MAX - 1
          If true, print "Stack overflow" and exit
Step 3: TOP = TOP + 1
Step 4: Insert the element: STACK[TOP] = ITEM
Step 5: Stop
```

## Algorithm for POP (array implementation)

```
Step 1: Start
Step 2: Check if TOP = -1
          If true, print "Stack underflow" and exit
Step 3: ITEM = STACK[TOP]
Step 4: TOP = TOP - 1
Step 5: Stop
```

> **Note:** the underflow check is `TOP = -1` (stack is **empty**). `TOP = MAX - 1` is the **overflow** check in PUSH, where the stack is **full**.

## C code 

```c
#define MAX 5

int stack[MAX];
int top = -1;

void push(int item) {
    if (top == MAX - 1) {
        printf("Stack overflow\n");
        return;
    }
    top = top + 1;
    stack[top] = item;
}

void pop() {
    if (top == -1) {
        printf("Stack underflow\n");
        return;
    }
    int item = stack[top];
    top = top - 1;
}
```

# 2. Using Linked List

In this method, the stack is implemented using **dynamic memory allocation**.

- Each element is stored in a **node** that contains a **data part** and a **next part**.
- The **TOP pointer** points to the **most recently inserted node**.
- Unlike the array implementation, there is **no fixed size limit** in this method.

```
 TOP
  │
  ▼
┌──────┬──────┐    ┌──────┬──────┐    ┌──────┬──────┐
│  30  │  ●───┼──► │  20  │  ●───┼──► │  10  │ NULL │
└──────┴──────┘    └──────┴──────┘    └──────┴──────┘
 (top node)                           (bottom node)
```

Both PUSH and POP happen at the **front** of the list, where TOP is. That's why we never need to travel through the list.

When the stack is empty, `TOP = NULL`.

## Algorithm for PUSH (linked list implementation)

```
Step 1: Start
Step 2: Create a node and assign memory
Step 3: Set NEWNODE -> DATA = ITEM
Step 4: Set NEWNODE -> NEXT = TOP
Step 5: Set TOP = NEWNODE
Step 6: Print "ITEM inserted successfully"
Step 7: Stop
```

How it works: the new node first **points to the old top** (Step 4), and then **TOP moves to the new node** (Step 5). The order matters. If you moved TOP first, you'd lose the rest of the stack.

```
Before:   TOP ─► [20|●]─► [10|NULL]

Step 4:   NEWNODE [30|●]─► [20|●]─► [10|NULL]       (new node points to old top)

Step 5:   TOP ─► [30|●]─► [20|●]─► [10|NULL]        (TOP moves to the new node)
```

## Algorithm for POP (linked list implementation)

```
Step 1: Start
Step 2: Check if TOP = NULL
          If true, print "Stack underflow" and exit
Step 3: Set TEMP = TOP
Step 4: Set ITEM = TOP -> DATA
Step 5: Set TOP = TOP -> NEXT
Step 6: Free the memory of the TEMP node
Step 7: Print "ITEM deleted"
Step 8: Stop
```

How it works: `TEMP` holds the old top node so we can free it **after** TOP has moved to the next node. Without `TEMP`, that node's memory would be lost (a **memory leak**).

## C code 

```c
#include <stdio.h>
#include <stdlib.h>

struct node {
    int data;
    struct node *next;
};

struct node *top = NULL;          // NULL means the stack is empty

void push(int item) {
    struct node *newnode = (struct node *) malloc(sizeof(struct node));
    if (newnode == NULL) {        // no memory left
        printf("Stack overflow\n");
        return;
    }
    newnode->data = item;
    newnode->next = top;
    top = newnode;
    printf("%d inserted successfully\n", item);
}

void pop() {
    if (top == NULL) {
        printf("Stack underflow\n");
        return;
    }
    struct node *temp = top;
    int item = top->data;
    top = top->next;
    free(temp);
    printf("%d deleted\n", item);
}
```

# Array vs Linked List Implementation of Stack 

| Basis | Using Array | Using Linked List |
|-------|-------------|-------------------|
| **Size** | Fixed (`MAX`), decided in advance | Not fixed, grows and shrinks at run time |
| **Memory allocation** | Static (compile time) | Dynamic (run time) |
| **Stack full when** | `TOP = MAX - 1` | Only when the system runs out of memory |
| **Stack empty when** | `TOP = -1` | `TOP = NULL` |
| **Memory usage** | Unused space is wasted if the array is bigger than needed | Extra memory needed for the next pointer in each node |
| **PUSH / POP** | Fast | Fast |

---

# Quick Revision

- A stack can be implemented using an **array** or a **linked list**.
- **Array:** fixed size `MAX`, `TOP` is the index of the top element. Overflow at `TOP = MAX - 1`, underflow at `TOP = -1`.
- **Linked list:** dynamic memory, each node has a data part and a next part, `TOP` points to the latest node. Underflow at `TOP = NULL`.
- Array PUSH: `TOP = TOP + 1`, then `STACK[TOP] = ITEM`.
- Array POP: take `ITEM = STACK[TOP]`, then `TOP = TOP - 1`.
- Linked list PUSH: `NEWNODE -> NEXT = TOP`, then `TOP = NEWNODE`.
- Linked list POP: `TEMP = TOP`, `TOP = TOP -> NEXT`, then free `TEMP`.
