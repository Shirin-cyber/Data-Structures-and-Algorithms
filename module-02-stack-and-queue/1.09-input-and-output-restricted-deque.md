# 2.9 Input Restricted and Output Restricted Deque

A **deque** (double ended queue) is a linear data structure in which **insertion and deletion** can be performed at **both ends**, the **front** and the **rear**.

However, depending on the **restriction placed on the operations**, there are **two types** of deque:

```
Deque
├── 1. Input Restricted Deque
└── 2. Output Restricted Deque
```

A normal deque allows all four operations:

| Operation | Allowed? |
|-----------|----------|
| Insert front | Yes |
| Insert rear | Yes |
| Delete front | Yes |
| Delete rear | Yes |

The two types below each **take away one operation**.

---

## 1. Input Restricted Deque

It is a type of deque in which **insertion is restricted to one end**, but **deletion is allowed from both ends**.

```
              ┌──────┬──────┬──────┬──────┐
 Delete ◄──── │  10  │  20  │  30  │  40  │ ◄──── Insert
  front       └──────┴──────┴──────┴──────┘        rear
              ▲                           │
              └─── Delete from rear too ──┘
```

### Example operations

| Operation | Status |
|-----------|--------|
| `Insert rear()` | Allowed |
| `Delete front()` | Allowed |
| `Delete rear()` | Allowed |
| `Insert front()` | **Not allowed** |

So here the **input (insertion)** is restricted, and it can only happen at the rear.

---

## 2. Output Restricted Deque

It is a type of deque in which **deletion is restricted to one end**, but **insertion is allowed at both ends**.

```
 Insert ──►   ┌──────┬──────┬──────┬──────┐   ◄── Insert
  front       │  10  │  20  │  30  │  40  │       rear
              └──────┴──────┴──────┴──────┘
              │
              ▼
        Delete front only
```

### Example operations

| Operation | Status |
|-----------|--------|
| `Insert front()` | Allowed |
| `Insert rear()` | Allowed |
| `Delete front()` | Allowed |
| `Delete rear()` | **Not allowed** |

So here the **output (deletion)** is restricted, and it can only happen at the front.

---

## Side-by-Side Comparison

| Operation | Input Restricted | Output Restricted |
|-----------|------------------|-------------------|
| **Insert front** | Not allowed | Allowed |
| **Insert rear** | Allowed | Allowed |
| **Delete front** | Allowed | Allowed |
| **Delete rear** | Allowed | Not allowed |
| **Restricted operation** | Insertion | Deletion |

> **Easy way to remember:**
> - **Input** restricted → **insertion** is restricted (input = putting things in).
> - **Output** restricted → **deletion** is restricted (output = taking things out).

---

## Connecting it to stack and queue 

Restricting a deque makes it look more like the structures we already know:

- An **input restricted deque** can act as a **queue** (insert at rear, delete from front) or as a **stack** (insert at rear, delete from rear).
- An **output restricted deque** can act as a **queue** (insert at rear, delete from front) or as a **stack** (insert at front, delete from front).

> **Note:** which end is restricted is a choice. Here, the input restricted deque allows insertion at the rear only. Some books show it the other way round (insertion at the front only), so use the version your syllabus gives.

---

## Quick Revision

- A **deque** allows insertion and deletion at **both ends**.
- **Input restricted deque:** insertion at **one end only**, deletion at both ends.
- **Output restricted deque:** deletion at **one end only**, insertion at both ends.
- Input restricted → `Insert front()` not allowed. Output restricted → `Delete rear()` not allowed.
